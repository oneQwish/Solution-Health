# Solution-Health

Проектная работа спринта 5: интеграционная архитектура для запуска мобильного приложения «Здоровье+».

| Папка | Что внутри |
|---|---|
| `Task1` | Таблица проблем текущей интеграционной архитектуры |
| `Task2` | Целевая контекстная диаграмма C4 Level 1 (`target-c4.drawio`, `target-c4.png`) и обоснование интеграций |
| `Task3.1` | Доставка результатов анализов: описание, сравнение вариантов, блок-схема потока |
| `Task3.2` | Запись с оплатой: sequence-диаграмма, выбор типа Saga, компенсации, идемпотентность |
| `Task3.3` | Спецификация OpenAPI для `GET /appointments` и комментарий |
| `Task4.1` | Параметры отказоустойчивости для 1С и платёжного шлюза, Circuit Breaker, снижение нагрузки на 1С |
| `Task4.2` | Стратегия горизонтального масштабирования |
| `Task4.3` | Аутентификация, rate limiting, защита каналов передачи |

Диаграммы открываются в draw.io (`.drawio`) или Mermaid (`.md`), PNG лежат рядом для просмотра.
