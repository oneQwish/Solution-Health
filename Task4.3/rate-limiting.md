| Тип запроса | Лимит | Действие при превышении |
|---|---|---|
| Поиск врачей (публичный, без токена) | 60 запросов в минуту на установку приложения (идентификатор установки передаётся в заголовке), допускается кратковременный всплеск до 20 запросов. Дополнительно 1 000 запросов в минуту с одного IP-адреса: за одним адресом мобильного оператора работает много абонентов, поэтому лимит по IP только отсекает массовый перебор. | Запрос не передаётся в систему, клиент получает ответ 429 Too Many Requests с заголовком Retry-After. При превышении лимита по IP адрес не блокируется надолго, а получает тот же ответ 429, и превышение фиксируется для анализа. |
| Создание записи к врачу (авторизованный) | 10 запросов в минуту на пациента (по идентификатору из токена) и не больше 3 записей пациента в статусе «ожидает оплаты» одновременно. | Запись не создаётся. При превышении частоты клиент получает 429 Too Many Requests с заголовком Retry-After, приложение показывает «Слишком много попыток, повторите позже». При превышении числа неоплаченных записей клиент получает 409 Conflict, приложение предлагает оплатить или отменить уже созданные записи. Превышения фиксируются в журнале безопасности. |
